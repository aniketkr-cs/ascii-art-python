# ASCII Art Project – Famous Personality (Minor II)

## Project Overview
This project is developed as part of the **Minor II coursework** to strengthen Python programming fundamentals.
The objective is to generate an **ASCII-style image of a famous personality** with the help of special symbols using only basic programming concepts such as loops, conditional statements, and logical thinking.

## Personality Chosen
Vladimir Putin

## Project Objective
- To practice nested loops and conditional logic in Python  
- To create ASCII-style output without using any external libraries  

## Approach Used
A reference image of the personality was studied only for **visual understanding** of the overall shape and proportions.
The image was manually simplified into a logical **row and column structure**, similar to a grid.

Each row of the ASCII art was implemented using conditional statements that decide
where special symbols should be printed based on column positions.

The entire ASCII output is generated **purely through Python logic**.

## Key Concepts Used
- Nested `while` loops  
- Conditional statements (`if / elif / else`)  
- Logical range checks  
- Grid-based design approach  

## Tools & Technologies
- Python 3  
- VS Code / Google Colab  

## How to Run the Project
1. Clone or download this repository  
2. Open the file `ascii_putin.py`  
3. Run the program using:
   ```bash
   python ascii_putin.py
4.   The ASCII-style output will be displayed in the terminal.

## Output Visualization
The ASCII output is generated as plain text in `output.txt`.

Due to the nature of ASCII art, the facial structure becomes clearer
when the output is viewed at a lower zoom level (70–80%).
For better visualization, a zoomed-out view is provided as `output_zoomed.png`.
